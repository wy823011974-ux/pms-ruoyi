# 项目管理系统 v2.0 — 使用说明

## 1. 环境要求

| 软件 | 版本 | 说明 |
|------|------|------|
| JDK | 17+ | 后端运行环境 |
| Maven | 3.9+ | 后端构建工具 |
| Node.js | 18+ | 前端构建工具 |
| Docker | 24+ | MySQL + Redis 容器 |
| MySQL | 8.0 | 通过 Docker 运行 |
| Redis | 7 | 通过 Docker 运行 |

## 2. 快速启动

### 2.1 启动基础设施

```bash
cd D:\project-ruoyi
docker compose up -d mysql redis
```

### 2.2 启动后端

```bash
cd backend
mvn spring-boot:run
```

后端运行在 http://localhost:8080

### 2.3 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端运行在 http://localhost:5173

### 2.4 默认账号

| 账号 | 密码 | 角色 |
|------|------|------|
| admin | admin123 | 超级管理员 |

## 3. 功能模块

### 3.1 仪表盘
- 查看项目总数、进行中项目、文件数、数据行数
- 快捷导航到各功能模块

### 3.2 项目管理
- **创建项目**：填写名称、年份、地区、类型（项目编码自动生成）
- **状态流转**：进行中 → 已完结 → 已归档（支持回退）
- **搜索筛选**：按状态筛选、按名称/编码搜索
- **软删除**：删除的项目可以恢复

### 3.3 项目类型配置（管理员）
- **项目类型管理**：创建/编辑/删除项目类型
- **文件类型配置**：定义每种项目需要哪些Excel文件
  - Sheet名称：指定读取哪个Sheet（留空=第一个）
  - 跳过行数：跳过标题行
  - 字段校验开关
- **字段定义**：定义Excel每一列的属性
  - 字段名称（中文）、字段标识（拼音）
  - 字段类型：text / number / date / select
  - 是否必填
- **Schema 导入/导出**：将完整配置导出为JSON，可在不同环境间迁移

### 3.4 调查数据管理
- **上传数据**：
  1. 选择数据类型（文件类型）
  2. 调整跳过行数
  3. 选择覆盖或新增模式
  4. 选择 Excel 文件上传
- **数据校验**：自动校验表头、必填字段、数据类型
- **数据脱敏**：自动识别并脱敏姓名、身份证、手机号、地址
- **数据查看**：分页表格，动态列显示
- **导出 Excel**：将脱敏数据导出为 Excel 文件
- **上传历史**：查看每次上传的结果

### 3.5 文件管理
- **上传文件**：支持 .xlsx / .xls / .docx / .pdf 等格式
- **版本管理**：覆盖上传（同版本号）或新增上传（版本号+1）
- **下载文件**：点击下载按钮获取原始文件
- **版本历史**：查看文件的所有历史版本

### 3.6 用户管理（管理员）
- **创建用户**：填写手机号、姓名、部门、邮箱、密码、角色
- **角色管理**：5种角色（超级管理员/管理员/负责人/成员/客户）
- **审批用户**：启用或禁用用户账号
- **重置密码**：管理员可重置其他用户密码
- **删除用户**：不可删除超级管理员

## 4. 业务类型说明

系统预置了3种业务类型：

### 4.1 体育场地常态化普查
- 文件类型：场地台账（汇总）、场地台账（分项）、场馆代码
- 用途：普查各类体育场地的基础信息

### 4.2 体育锻炼达标测验
- 文件类型：单项成绩表、总成绩表
- 用途：记录国家体育锻炼标准达标测验成绩
- Excel首行为标题行，需要设置 skipRows=1

### 4.3 国民体质监测
- 文件类型：常态化（幼儿/成人/老年）、非常态化（幼儿/成人/老年）
- 用途：记录国民体质监测各项指标数据

## 5. 数据脱敏规则

系统在上传数据时自动对敏感信息脱敏：

| 敏感类型 | 识别规则 | 脱敏示例 |
|----------|----------|----------|
| 姓名 | 字段名含 name/xing_ming | 张三 → 张* |
| 身份证 | 字段名含 id_card/shen_fen | 110101199003071234 → 110101********1234 |
| 手机号 | 字段名含 phone/shou_ji/tel | 13800138001 → 138****8001 |
| 地址 | 字段名含 address/di_zhi | 海南省海口市龙华区金贸西路100号 → 海南省海口市龙华区******** |

> 脱敏在入库前执行，原始数据不会存储在数据库中。

## 6. API 接口

### 认证
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/login | 登录 |
| POST | /api/auth/register | 注册 |
| GET | /api/auth/me | 获取当前用户 |
| PUT | /api/auth/change-password | 修改密码 |

### 项目管理
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/projects | 项目列表（支持筛选） |
| POST | /api/projects | 创建项目 |
| PUT | /api/projects/{id} | 更新项目 |
| DELETE | /api/projects/{id} | 软删除项目 |
| PUT | /api/projects/{id}/status | 状态流转 |

### 调查数据
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/projects/{pid}/upload-data | 上传数据 |
| GET | /api/projects/{pid}/survey-data | 查询数据 |
| GET | /api/projects/{pid}/survey-data/export | 导出Excel |
| DELETE | /api/projects/{pid}/survey-data/{id} | 删除单条 |
| DELETE | /api/projects/{pid}/survey-data/clear | 清空 |
| GET | /api/projects/{pid}/upload-history | 上传历史 |
