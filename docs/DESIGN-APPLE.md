# PMS 项目管理系统 — Apple 风格设计文档

> 版本：v3.0-apple  
> 日期：2026-05-28  
> 设计参考：Apple Human Interface Guidelines

---

## 1. 设计哲学

**场景**：数据管理员在明亮办公室内长时间盯着屏幕审阅调查数据。设计必须减少视觉疲劳，保持清晰可扫描。

**核心原则**（源自 Apple HIG）：
- **清晰**：文字在任何尺寸下清晰可读，图标精确且有意义
- **顺从**：设计服务于内容，不喧宾夺主
- **纵深**：通过透明度、阴影、模糊构建清晰的视觉层级

## 2. 色彩系统

采用 Apple 风格的 **Restrained** 策略——柔和中性背景 + 单一强调色。

| 角色 | 色值 | CSS 变量 | 用途 |
|------|------|----------|------|
| 强调色 | `#007AFF` | `--apple-blue` | 主按钮、选中态、链接 |
| 背景 | `#F2F2F7` | `--apple-bg` | 页面背景（iOS 系统灰） |
| 卡片 | `#FFFFFF` | `--apple-surface` | 卡片、表格、弹窗 |
| 分组背景 | `#E5E5EA` | `--apple-grouped` | 分组容器背景 |
| 主文字 | `#1C1C1E` | `--apple-text` | 标题、正文 |
| 次要文字 | `#8E8E93` | `--apple-text-secondary` | 辅助信息、标签 |
| 分隔线 | `#E5E5EA` | `--apple-separator` | 分割线、边框 |
| 成功绿 | `#34C759` | `--apple-green` | 状态-启用/成功 |
| 警告橙 | `#FF9500` | `--apple-orange` | 状态-警告 |
| 危险红 | `#FF3B30` | `--apple-red` | 状态-删除/危险 |
| 半透明填充 | `rgba(120,120,128,0.16)` | `--apple-fill` | 按钮填充、标签背景 |
| 半透明填充2 | `rgba(120,120,128,0.12)` | `--apple-fill-secondary` | 次级填充 |

## 3. 字体排版

- **字体栈**：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "Helvetica Neue", sans-serif`
- **层级**：

| 级别 | 大小 | 字重 | 用途 |
|------|------|------|------|
| 大标题 | 28px / 700 | 页面主标题 |
| 标题1 | 22px / 600 | 卡片标题、弹窗标题 |
| 标题2 | 17px / 600 | 分组标题 |
| 正文 | 15px / 400 | 表格内容、正文 |
| 辅助文字 | 13px / 400 | 标签、描述 |
| 小字 | 11px / 400 | 角标、时间戳 |

- **行高**：1.4（标题）、1.6（正文）
- **字间距**：-0.2px（大标题）、0（正文）

---

## 4. 间距与布局

采用 4pt 基础网格，与 iOS 一致：

| Token | 值 | 用途 |
|-------|-----|------|
| `pt-2` | 8px | 紧凑间距 |
| `pt-3` | 12px | 内容内间距 |
| `pt-4` | 16px | 标准边距 |
| `pt-5` | 20px | 卡片 padding |
| `pt-6` | 24px | 段落间距 |
| `pt-8` | 32px | 大分隔 |

- **最大内容宽度**：1200px（桌面端）
- **侧边栏宽度**：260px（扩展至 iOS iPad 侧边栏比例）

## 5. 圆角

| 元素 | 圆角 | 说明 |
|------|------|------|
| 大卡片/弹窗 | 16px | 接近 iOS 连续圆角 |
| 小卡片/按钮 | 12px | 列表行、输入框 |
| 标签/徽章 | 8px | 状态标签 |
| 全宽按钮 | 8px | 胶囊形 |

## 6. 阴影与纵深

Apple 风格使用极淡阴影表现层级：

| 级别 | 值 | 用途 |
|------|-----|------|
| 浮层 | `0 1px 3px rgba(0,0,0,0.04)` | 卡片 |
| 弹窗 | `0 8px 32px rgba(0,0,0,0.12)` | 模态框 |
| 导航 | `0 0.5px 0 rgba(0,0,0,0.08)` | 顶栏底部分隔 |

---

## 7. 动效

| 属性 | 值 |
|------|-----|
| 时长 | 200ms（微交互）/ 350ms（页面过渡） |
| 曲线 | `cubic-bezier(0.25, 0.1, 0.25, 1.0)`（iOS 默认） |

- 按钮 hover：轻微透明度变化 + 上浮 1px
- 卡片 hover：阴影增强 + 上浮 2px
- 页面过渡：淡入 200ms

## 8. 组件规范

### 侧边栏
- 半透明深色背景 `rgba(28,28,30,0.95)` + 轻微模糊 `backdrop-filter: blur(20px)`
- 选中项：半透明白色填充 + 左侧 3px 指示条
- 图标：SF Symbols 风格线性图标，20px

### 卡片
- 白色表面、16px 圆角、极淡阴影
- 标题左对齐，操作按钮右上
- 内边距 20px

### 表格
- 去掉纵向分割线，仅保留行底部分隔线
- 表头：小写或正常的标签，13px 灰色
- 行 hover：极淡的灰色底色 `rgba(0,0,0,0.02)`

### 按钮
- 主按钮：蓝底白字，12px 圆角，轻微 shadow
- 次按钮：透明底 + 蓝边框
- 危险按钮：红色文字 + 透明底

### 输入框
- 浅灰背景 `rgba(118,118,128,0.12)`、12px 圆角
- 聚焦时蓝边框
- placeholder 用灰色而非浅灰（对比度足够）

## 9. 各页面定制

| 页面 | 特殊设计 |
|------|----------|
| 登录页 | 全屏浅灰背景 + 居中白色卡片 + 顶部 Logo 位 |
| 仪表盘 | 统计卡片轻量底色区分（蓝/绿/橙/紫） |
| 项目管理 | 3 列卡片网格 + 悬停效果 |
| 调查数据 | 纯白表格 + 行间淡灰分隔线 |
| 用户管理 | 表格 + 下拉菜单操作 |

---

## 10. 禁止项（Impeccable 绝对禁令）

- 侧条纹边框（border-left/border-right 装饰）
- 渐变文字（background-clip: text）
- 玻璃态作为默认风格
- Hero-metric 模板化卡片
- Emoji 作为图标
- 等大同质的卡片网格
- 模态框作为第一选择
