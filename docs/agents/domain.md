# Domain Docs

本仓库使用 **单上下文（single-context）** 布局。

## 结构

```
/
├── CONTEXT.md              ← 领域术语表（项目通用词汇定义）
├── docs/adr/               ← 架构决策记录（ADR）
│   ├── 0001-xxx.md
│   └── 0002-xxx.md
└── docs/agents/            ← 本文件（Agent 接入配置）
```

## Agent 使用规则

处理功能开发或 Bug 修复时，按以下顺序读取文档：

1. 先读 `CONTEXT.md`，理解领域模型和术语
2. 检查 `docs/adr/`，确认历史决策是否约束当前方案
3. 如果文件不存在，**静默跳过**，不要提醒用户创建。`/grill-with-docs` 会在术语或决策确定时自动创建它们

## 使用术语表词汇

输出中提及领域概念时，使用 `CONTEXT.md` 中定义的词汇，避免同义替换。

如果一个概念在术语表中不存在：
- 可能是你在引入项目不使用的语言 → 换回已有词汇
- 可能确实缺了这个概念 → 标记下来，留给 `/grill-with-docs` 处理

## 标记 ADR 冲突

如果输出与已有 ADR 矛盾，显式指出而非静默覆盖：

> _与 ADR-0007 冲突 — 但值得重新讨论，因为…_
