# Triage Labels

五个标准分类标签，使用中文。

| 技能内部名 | 本仓库标签 | 含义 |
|-----------|-----------|------|
| `needs-triage` | `待评估` | 新提交，尚未审查，等待维护者评估 |
| `needs-info` | `待补充` | 信息不足，等待提问者补充更多细节 |
| `ready-for-agent` | `AI可处理` | 描述完整清晰，可以交给 AI Agent 实现 |
| `ready-for-human` | `需人工` | 需求明确，但需要人工判断或动手实现 |
| `wontfix` | `不处理` | 决定不做，关闭并附上原因 |

## 工作流

1. 新 Issue 默认标 `待评估`
2. 信息不够 → 改为 `待补充`，等待提问者回应
3. 信息齐全 → 根据复杂度标 `AI可处理` 或 `需人工`
4. 决定不做 → 标 `不处理` 并关闭

## 技能使用

当技能说"打上 AI 可处理的标签"时，用 `AI可处理`——对应关系见上表。
