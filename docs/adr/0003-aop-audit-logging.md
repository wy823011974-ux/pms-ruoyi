# ADR-0003: 使用 AOP 切面实现审计日志

**日期**: 2026-05-27  
**状态**: 已采纳

## 背景

需要记录所有关键操作（登录、创建项目、上传数据等）的审计日志，但不能侵入业务代码。

## 决策

使用 Spring AOP + 自定义 `@Auditable` 注解实现声明式审计日志。

## 理由

1. 非侵入式：业务代码只需加注解，不需要写日志代码
2. 统一处理：IP获取、用户ID获取、参数序列化等逻辑集中在切面中
3. 异步安全：切面用 try-finally 确保操作失败也记录日志
4. 灵活过滤：可通过 `@Auditable(action, targetType)` 精确标记需要审计的方法

## 后果

- 审计日志表 `sys_audit_log` 需定期清理（建议保留1年）
- AOP 有轻微性能开销（~1ms），但在可接受范围内
